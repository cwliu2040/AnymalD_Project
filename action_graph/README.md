# Isaac Sim Action Graph Boundary

Reserved for future Isaac Sim 5.1 ROS 2 Bridge / Action Graph assets and setup
documentation.

The graph will transport commands and simulated sensor/robot state between
Isaac Sim and the external ROS 2 process. It will not embed `rclpy` in Isaac
Sim Python and will not use UDP as the final transport.

No runtime graph is implemented in the Flat Locomotion v1 baseline phase.
